# Иллюстрации к квесту «Корзинка Каперусины»

Созданы встроенным image_gen по скиллу imagegen.

- `index.html` — галерея 38 выбранных иллюстраций и листов элементов.
- `illustrations/` — PNG оригинального размера.
- `illustrations/drafts/` — 6 ранних вариантов до исправлений.
- `generation-manifest.json` — полный набор запросов, источники, пути и SHA-256 всех 44 файлов.

Это статичные иллюстрации, а не готовые анимированные спрайты. Предметы, корзинки и улики представлены листами; слои не вырезались. Генерация остановлена по просьбе пользователя.
