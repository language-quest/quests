# Голос через SLNG — запуск

Web Speech API заменён на SLNG. Ключ живёт **только на сервере**: браузер ходит в локальный
прокси `tools/slng-proxy.mjs`, прокси — в `{region}.api.slng.ai`.

## Запуск

```bash
cd /Users/andreyryazanov/Desktop/apps/language_quest && node tools/slng-proxy.mjs .
```

Открыть **http://localhost:5179/web/** (корень `/` редиректит туда же).
Прокси раздаёт и статику, отдельный `http.server` не нужен.

Конфигурация читается из `.env.local` (уже в `.gitignore`); заданное в окружении имеет приоритет.

```bash
curl -s http://localhost:5179/api/health
```

В правом верхнем углу приложения видно, через что идёт голос: **«голос: SLNG …»** или
**«голос: браузер»**. Наведение показывает модели и причину фолбэка.

## Переменные

| Переменная | Значение | Примечание |
|---|---|---|
| `SLNG_API_KEY` | ключ | также принимается `VOICEAI_API_KEY` |
| `SLNG_REGION` | `eu-west` | задаёт поддомен: `https://eu-west.api.slng.ai` |
| `SLNG_STT` | `deepgram/nova:3` | |
| `SLNG_STT_LANGUAGE` | `es` | **критично, см. ниже** |
| `SLNG_TTS` | `deepgram/aura:2` | |
| `SLNG_TTS_VOICE` | `aura-2-javier-es` | |

## Три вещи, которые выяснились на живом ключе

### 1. Язык STT передаётся полем формы, а не query-параметром

Это главное. Как query-параметр `language` молча игнорируется, и испанская речь
транскрибируется английской фонетикой.

| Как передан | «queso» распознано как |
|---|---|
| `?language=es` в URL | `whistle` |
| поле формы `language=es` | `hueso` ✓ |

Замеры после исправления (круг синтез → распознавание, синтетический голос):

| Сказано | Распознано | Уверенность |
|---|---|---|
| Más despacio, por favor | `más despacio por favor` | 0.99 |
| ¿Puedes hablar más alto? | `puedes nadar más alto` | 0.99 |
| ¿Puedes repetir? | `puedes repetir` | 0.99 |
| queso | `hueso` | 0.98 |
| manzana | `manzana` | 0.52 |

Интент-гейт на этих транскриптах: **6/6**, включая отрицательный случай («hola que tal» →
совпадения нет). «puedes nadar más alto» проходит, потому что гейт ищет коммуникативную
функцию, а не точную фразу: «más alto» на месте.

### 2. В eu-west по HTTP развёрнута ровно одна STT-модель

`GET /v1/catalog/models` перечисляет 18 STT-моделей, но каталог **не фильтрует по
развёрнутым** — SLNG об этом предупреждает в своей документации. Фактически:

| Модель | Ответ |
|---|---|
| `deepgram/nova:3` | 200 ✓ |
| `slng/deepgram/nova:3-es`, `-multi` | 503 `No deployments found` |
| `soniox/*`, `speechmatics/*`, `gradium/*` | 405 — WebSocket-only |

То есть испанский приходится получать не отдельной моделью, а параметром языка к `nova:3`.

### 3. Испанский на Aura 2 жив

Я раньше написал, что испанский Aura 2 снят с эксплуатации — **это было неверно**. Снят
идентификатор *модели* `aura:2-es`; голос `aura-2-javier-es` на модели `deepgram/aura:2`
работает. Проверено живым синтезом: WAV 24 кГц моно.

## Ответ STT приходит в нативной форме Deepgram

Не плоский `{transcript}`, как в общей документации SLNG, а
`results.channels[0].alternatives[0].transcript`. Прокси разбирает обе формы и отдаёт клиенту
`{ transcript, confidence, language, ms }`.

## Что уходит в SLNG, а что нет

**Уходит:** голос родителя. Это тот случай, где фронтенд SLNG даёт реальную пользу: шумная
комната, рядом трёхлетка, неродной испанский.

**Не уходит:** голос ребёнка. Граница из `architecture.md` §11 соблюдена буквально — слово
ребёнка распознаётся браузером локально и на прокси не отправляется. До появления on-device
детектора это единственный честный вариант; маршруты «сказать вместе» и касание работают всегда.

## Кэш синтеза

Прокси складывает аудио в `assets/caperucita/tts-cache/` по хэшу `модель+голос+текст`.
Авторские реплики повторяются, поэтому со второго раза отдаются мгновенно и без сети — это и
есть «предрендеренные авторские реплики» из архитектуры, набираемые постепенно.
Заголовок `x-cache: hit|miss` показывает источник.

## Деградация

| Отказ | Поведение |
|---|---|
| Ключа нет | Бейдж «голос: браузер», работает `SpeechSynthesis` |
| SLNG вернул ошибку | Тело ошибки в лог и клиенту (не глотаем), синтез фолбэком в браузер |
| Прокси недоступен | То же |
| Микрофон запрещён | Остаются «Сказать вместе» и автопереход на 120 с |

Проверено: при `slng:false` квест проходится целиком.

## Деплой на Cloudflare Workers (статика)

`wrangler.jsonc` раздаёт `dist/`, который собирает `node tools/build-static.mjs`
(страницы + только нужные картинки, ~39 МБ; раскладка `web/` и `assets/` та же,
что в репозитории, поэтому `../assets/...` работает). В Cloudflare: Workers & Pages →
Create → Import a repository → ветка `main`; сборка запускается из `wrangler.jsonc` (`build.command`),
Build command можно оставить пустым, Deploy command `npx wrangler deploy`. Каждый push в `main` выкатывается сам.
Игра открывается с `/` (редирект на `/web/quests.html`). Голос (`/api/*`) на статике
не работает — там нужен прокси; без него игра идёт без озвучки.
