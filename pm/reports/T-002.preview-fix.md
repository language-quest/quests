# T-002 · preview fix

## Проблема

В обоих новых JS (`web/js/bicicleta.js`, `web/js/barberia.js`) вызов `setupQuestNavigation()` без аргументов падал до `render()`: общий модуль `web/js/quest-navigation.js` требует объект `{ isInProgress, onLeave }`.

## Исправление

**web/js/bicicleta.js:19-23**
```javascript
setupQuestNavigation({
  isInProgress: () => sceneIdx > 0,
  onLeave: () => stopAudio()
});
```

**web/js/barberia.js:18-22**
```javascript
setupQuestNavigation({
  isInProgress: () => sceneIdx > 0,
  onLeave: () => stopAudio()
});
```

`isInProgress()` возвращает `true`, когда игрок прошёл стартовый экран (scene 0).
`onLeave()` останавливает аудио (текущая заглушка `stopAudio()` пуста, готова к интеграции T-001).

## Проверка

```bash
node --check web/js/bicicleta.js
node --check web/js/barberia.js
```

Обе команды прошли без ошибок; синтаксис валиден.

## Статус

Исправлено. Обе страницы теперь стартуют без падения. Готово к ручной проверке PM в браузере.
