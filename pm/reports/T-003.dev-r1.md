# T-003 · отчёт разработчика, раунд 1

## Что сделано
- `web/coworking.html` — новая страница квеста; `web/js/coworking.js` — самостоятельный движок; `web/js/coworking-data.js` — все сцены, испанские строки дословно из ТЗ, постоянные ID (`s1.a.r`, `s0.lucia`, …).
- 18 шагов (сцены 0–11), реакции ровно по ТЗ; карточки перемешиваются один раз при входе в шаг; `locked` защищает от двойного клика (проверено `click()` ×2 на каждой карточке).
- Изображения-карточки (сцены 1, 2, первая половина 7): `aria-label="Opción A/B/C"`, `alt=""`, `src` — blob-URL, имя файла в DOM не виден. Остальные карточки — только текст.
- Состояние-сцена — SVG из слоёв (`sceneSvg` в `coworking.js`): стол/кабель/заряд, телефон Дани, листы, карточки брони, кабинка с тремя, переговорная, новичок. Финал — `cover.png` + слои, брони «исходная + исправленная».
- Журнал `Tus usos del español`: 9 целей × 2 употребления по матрице, реальные выбранные фразы и реакции, без оценок. `Volver a jugar` сбрасывает состояние.
- Каталог: карточка в `web/quests.html`. `setupQuestNavigation({ isInProgress, onLeave })` с объектом, `onLeave` останавливает аудио.
- PNG скопированы в `assets/coworking/` (в главном чекауте они untracked).
- Русский только в `<details>` «vocabulario».

## Отступления от ТЗ
- **Аудио не подключено — блокер T-001** (`dev-failed`). Реплики ищутся как `assets/coworking/audio/<id>.mp3` / `<id>.slow.mp3`; файла нет → показывается «Todavía no hay audio para esta frase.» и `Continuar` доступен сразу. Кнопки `Volver a escuchar` / `Más despacio` есть. Runtime TTS и `speechSynthesis` не используются.
- Строки квеста не включены в `validate-tts-text.mjs` (он читает только два quest.json) — орфография coworking-текста не проверена автоматически.
- Эффекты «заглянул в пустую кабинку», «соседи оборачиваются», «дверь приоткрывается», «принтер останавливается» не анимированы отдельно — только итоговое состояние сцены.
- Сцена-состояние графически простая (плоский SVG), не 3D-стиль PNG.
