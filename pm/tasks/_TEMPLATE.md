## Сцена

## Карточки

Главное правило: **картинка не переводит слово**. На одной карточке не может быть
одновременно испанской фразы и картинки, которая её объясняет. Эмодзи — такая же
подсказка, как фотография. Выбери ровно одну форму для всего набора:

- [ ] **картинки** — предмет/цвет/форма + нейтральная подпись `A` / `B` / `C` (или без подписи)
- [ ] **фразы** — испанский текст, картинок нет

## Реакция на неверный выбор

Ошибка не наказывается, а объясняется: из ответа персонажа игрок должен понять,
что означало выбранное слово. Перебор — это и есть механика обучения.

| Выбор | Что отвечает персонаж (исп.) | Что игрок из этого понимает |

| B | | |
